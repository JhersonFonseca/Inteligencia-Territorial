# Evidencia con datos oficiales: pendiente

Esta carpeta es solo para la validación con datos oficiales: cargas desde los servicios y descargas
registradas, y mapa base real de OpenStreetMap. Se llena siguiendo `docs/validacion_local.md`.

Todavía está vacía: el entorno de desarrollo no tiene acceso a esos servicios.

`herramientas/verificar_mapa.py --datos reales` solo aprueba si cada capa procede de una fuente
oficial verificada. La evidencia sintética no puede guardarse aquí: la herramienta lo rechaza.
